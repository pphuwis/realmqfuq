ดู Analytics บน Cloudflare
Visitors, Page views, Top pages, Countries และอื่นๆ อยู่ที่ Cloudflare Dashboard ครับ
📋 วิธีเพิ่ม Web Analytics ให้เว็บ
ℹ️ ทำครั้งเดียว แล้วดูสถิติได้เลยบน Cloudflare Dashboard
1
เปิด Cloudflare Dashboard
ไปที่ dash.cloudflare.com → เมนูซ้าย → Analytics → Web Analytics
2
Add a site
กด Add a site → กรอก URL ของ pages.dev → Cloudflare จะให้ script snippet มา
3
ใส่ script ในหน้าเว็บ
วาง script ก่อน </head> ในทุกหน้าที่อยากติดตาม หน้าตาประมาณนี้:
<script defer
  src='https://static.cloudflareinsights.com/beacon.min.js'
  data-cf-beacon='{"token": "YOUR_TOKEN"}'>
</script>
✓
เสร็จแล้ว!
push ขึ้น GitHub → Cloudflare Pages deploy ให้ → ข้อมูล analytics จะเริ่มเข้ามาใน 1-2 ชั่วโมง ดูได้ที่ปุ่มด้านบนเลย

🔌 Connect to MC Bridge Server
ตั้งค่า Bridge Server บน VPS ก่อน แล้วกรอก URL และ Token ด้านล่าง

Setup บน VPS:
1. อัปโหลด mc-bridge-server.js ไปที่ VPS
2. รัน: npm install express ws rcon-client
3. ตั้งค่า ENV: BRIDGE_TOKEN, RCON_PASS, MC_DIR, MC_JAR
4. รัน: BRIDGE_TOKEN=mytoken RCON_PASS=mypass node mc-bridge.js
5. เปิด port 25580 ใน firewall

server.properties ต้องมี:
enable-rcon=true · rcon.port=25575 · rcon.password=mypass
